# 📊 Superstore Sales Dashboard

## 📌 Project Overview

The Superstore Sales Dashboard is an interactive data analysis project built using Microsoft Excel. It provides insights into sales performance across different product categories, regions, and customer segments.

The dashboard is designed to help understand business trends, identify high-performing areas, and support data-driven decision-making.

---

## 🎯 Objectives

* Analyze overall sales and profit performance
* Identify top-performing categories and regions
* Understand customer segment contributions
* Track monthly sales trends over time
* Build an interactive dashboard for dynamic analysis

---

## 🛠️ Tools & Technologies Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers (for interactivity)
* Data Cleaning & Transformation

---

## 📂 Dataset

* Superstore dataset (commonly used for analytics projects)
* Contains:

  * Order Date
  * Sales
  * Profit
  * Category
  * Region
  * Segment

---

## 📊 Dashboard Features

### 🔹 Sales Analysis

* Sales by Category
* Sales by Region
* Sales by Segment

### 🔹 Profit Analysis

* Profit by Category
* Profit by Segment

### 🔹 Time Analysis

* Monthly Sales Trend (2011–2014)

### 🔹 Interactivity

* Slicers for:

  * Category
  * Region
  * Segment
* Enables dynamic filtering across all charts

---

## 📈 Key Insights

* Technology category generates the highest sales and profit
* Consumer segment contributes the largest share of revenue
* Central region shows strong sales performance
* Sales trend shows consistent growth over the years
* Some categories have high sales but relatively lower profit margins

---

## 🎨 Dashboard Design

* Clean and structured layout
* White chart backgrounds for readability

* Clear differentiation between sales and profit metrics
